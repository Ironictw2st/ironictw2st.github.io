Overview Mod Manager Script Extender se.* API Reference

Two standalone Windows tools for Total War: THREE KINGDOMS. They work with any mod setup, not just 190 Expanded — but the two are built together, and the mod manager is the supported way to run the script extender.

器

TK Mod Manager

Replaces the CA launcher. Real load-order control, profiles, movie packs, Workshop metadata, conflict detection, and one-click script-extender injection.

  • Drag mods into the order you actually want
  • Profiles for separate mod setups
  • Status dots for out-of-date and superseded packs
  • Never copies, renames or moves your pack files
  • Portable and self-updating
術

TK Script Extender

A native DLL injected into the running game that registers extra se.* functions into the campaign Lua VM — things the stock script interface simply cannot do.

  • Move characters between faction recruitment pools
  • Recruit, replace and disband retinue units
  • Edit experience, skill points and faction potential
  • Buildings, effect bundles, income lines, auto-resolve
  • Verifies the game build before it touches anything

How they fit together

The mod manager launches the game directly rather than going through the CA launcher, so it controls the real load order. If you tick Script extender in the launch panel, it also downloads the matching DLL, checks it against your game build, and injects it once the main menu is up.

You do not need the script extender to use the mod manager. You do need the mod manager — or a manual injector — to use the script extender.

For mod authors A pack declares that it needs the script extender by shipping an SE/script_extender.json file. The manager reads it, marks the mod with an SE chip, and warns before launch if the installed DLL falls outside the version range. How to declare it →

Requirements

  • Windows, 64-bit. Both tools are native Windows apps.
  • Total War: THREE KINGDOMS. The script extender targets build 1.7.2.0 and stays inert on anything else.
  • Steam running, for the mod manager's Workshop features and for launching a Steam copy. Epic and Game Pass copies are supported too.
  • The script extender is single-player and campaign only. Multiplayer support exists but is not yet verified on two machines.
